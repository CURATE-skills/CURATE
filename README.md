# skill-curate

**curate-skills** is a Claude Code plugin that turns a plain-language description of a scientific
workflow into a FaaSr serverless workflow, stage by stage, with your approval at each gate.

```bash
git clone https://github.com/laurakuo1006/skill-curate.git
```

Install, quick start, deploy and troubleshooting: [curate-skills/README.md](curate-skills/README.md).
